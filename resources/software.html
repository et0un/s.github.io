Программное обеспечение

Инструменты для сценариев, веб-проектов, генеративной графики и живого показа. Набор выбирается под проект: устанавливать всё сразу не требуется.

С чего начать

Для первых веб-прототипов достаточно современного браузера и p5.js Web Editor. Для работы с файлами на своём компьютере добавьте Visual Studio Code. Сценарий с выборами можно проверить в Twine ещё до создания графики. TouchDesigner и Resolume нужны для соответствующих тем курса.

HTML, CSS и JavaScript составляют основу веб-проектов. Библиотека помогает решать конкретную задачу, но не заменяет понимания событий, состояния и обратной связи. Браузер также служит средой проверки: инструменты разработчика показывают ошибки, сетевые запросы и поведение страницы.

Веб: базовый набор

p5.js Web EditorБыстрый запуск графики в браузере без локальной установки. Удобен для первых экспериментов с движением и вводом.p5.jsБиблиотека JavaScript для творческого программирования: 2D-графика, анимация и взаимодействие.Visual Studio CodeРедактирование HTML, CSS и JavaScript в локальном проекте. Подходит, когда нужно управлять несколькими файлами.MDN: основы веб-разработкиРусскоязычный учебный раздел: структура страницы, оформление и программирование поведения. Это справочный материал, а не программа для установки.

Веб: расширение под задачу

Для 3D-сцены можно подключить Three.js, для синтеза и музыкального времени Tone.js. Не каждому проекту нужен сервер: локальный выбор и состояние можно реализовать в браузере. Общая сессия нескольких участников или совместные данные требуют отдельного решения для обмена и хранения.

Three.js3D-графика в браузере: объекты, камера, материалы и свет. Имеет смысл, когда пространственная сцена поддерживает идею.Tone.jsЗвук в браузере, синтез и планирование музыкальных событий. Подходит для звуковых интерактивных проектов.

Камера и микрофон требуют разрешения пользователя; браузер может ограничивать автоматическое воспроизведение звука. В сценарии нужно предусмотреть запуск по действию и понятный ответ при отказе в доступе. Веб-проект проверяют на целевом устройстве, а не только в редакторе.

Сценарии и структура взаимодействия

TwineВизуальная карта связанных текстовых фрагментов. Позволяет проверить выборы, маршруты и текстовый прототип истории.ink / InkyЯзык сценариев и редактор с предпросмотром. Для условных сцен, переменных и более сложного ветвления.LOOPYНебольшой браузерный инструмент для моделирования связей и обратной связи. Полезен при обсуждении системного поведения.

Twine и Inky решают похожую задачу разными способами. Для начала достаточно одного из них. Схема состояний может быть нарисована в любом привычном редакторе: важнее подписать события и условия, чем выбрать особую программу.

Графика, инсталляции и живой показ

TouchDesignerВизуальное программирование: обработка изображений и числовых каналов, генеративная графика, интерактивные системы.Resolume Avenue / ArenaСлои, клипы и эффекты для живого видео. Arena добавляет возможности для более сложного вывода и маппинга.Resolume WireОтдельная узловая среда для собственных источников, эффектов и режимов наложения в Resolume.Resolume AlleyПросмотр и конвертация медиа, в том числе подготовка DXV для Resolume.

Для знакомства с TouchDesigner подходит Non-Commercial: бесплатное некоммерческое использование, ограничение изображения 1280 × 1280 и ограничения по функциям. Условия Resolume и Wire, пробные режимы и возможности редакций проверяйте на официальных сайтах перед установкой. Выбор платной редакции зависит от задачи показа.

Игровые и пространственные проекты

Движок нужен, когда проект опирается на игровые объекты, физику, камеры и правила поведения в сцене. Для первых небольших 2D- и 3D-прототипов можно рассмотреть Godot. Unity и Unreal Engine остаются вариантами для более сложных проектов и работы с существующими материалами. Осваивать все три одновременно не требуется.

GodotОткрытый движок для 2D- и 3D-проектов. Экспорт в веб имеет ограничения: проверяйте совместимость выбранных функций и языка.UnityИгровые сцены, приложения и интерактивные прототипы. Выбор оправдан требованиями проекта или уже знакомым рабочим процессом.Unreal EngineТрёхмерные пространства и проекты в реальном времени, в том числе с визуальной логикой Blueprint.

Подготовка материалов и фиксация результата

BlenderПодготовка 3D-моделей, материалов и анимации для последующего использования в сцене.AudacityЗапись, обрезка и обработка звука для прототипа.OBS StudioЗапись экрана и звука, демонстрация работы проекта и фиксация живого показа.GitИстория изменений файлов проекта. Помогает возвращаться к рабочим версиям и сравнивать правки.GitHubХранение репозитория и совместная работа. Для небольшого статического веб-проекта можно использовать GitHub Pages.

Для начальной работы хватит одного редактора изображения и одного инструмента записи. Отдельная звуковая станция, медиасервер или приложение для управления светом добавляются, если проект действительно требует этих возможностей.

Как собрать набор для своего проекта

  1. История с выбором: Twine или Inky, затем браузер для проверки прохождения.
  2. Интерактивная веб-графика: p5.js и браузер; VS Code и Git при переходе к локальному проекту.
  3. 3D-проект: Three.js для браузера или один выбранный игровой движок; Blender для подготовки объектов.
  4. Инсталляция: TouchDesigner и выбранный источник данных. Способ подключения камеры, датчика или сети определяется отдельно.
  5. Аудиовизуальный сет: Resolume, подготовленные медиа и понятное управление; Wire для собственных инструментов.

Сначала проверьте основное взаимодействие в небольшом прототипе. После этого становится понятнее, какие инструменты действительно нужны, какие данные они должны передавать друг другу и где проект будет работать.
